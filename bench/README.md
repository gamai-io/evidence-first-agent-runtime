# Benchmark corpora

This directory contains **generated corpora**, not an independent red-team
engagement. They answer one narrow question:

> How often does the detector block differently-worded attacks, and how well
> does an antibody learned from one sample generalize to a paraphrase?

The v1 corpus was originally held out. The v2 lexicon was developed with it in
view, so `HELDOUT_REPORT.md` is a **development** result. `FINAL_REPORT.md`
comes from a second corpus generated after v2 was frozen.

## Files

| File | Purpose |
|---|---|
| `gen_attacks.py` | deterministic v1 generator (200 attacks, 100 benign) |
| `attacks_heldout.jsonl` | v1 attacks, each with a variant |
| `benign_heldout.jsonl` | 100 ordinary v1 tasks |
| `benign_hard.jsonl` | 54 hard-negative benign probes |
| `run_heldout.py` | development measurements |
| `heldout_results.json` | latest development run |
| `HELDOUT_REPORT.md` | human-readable development summary |
| `gen_final.py` | second-corpus generator, written after v2 froze |
| `attacks_final.jsonl` | 90 differently-worded attacks |
| `benign_final.jsonl` | 40 second-check benign tasks |
| `run_final.py` | second-check measurements |
| `final_results.json` | latest second-check run |
| `FINAL_REPORT.md` | human-readable second-check summary |
| `attacks_edge.jsonl` | 70 edge-case attacks |
| `benign_edge.jsonl` | 50 edge benign tasks |
| `run_edge.py` | edge regression measurements |
| `edge_results.json` | latest edge run |
| `EDGE_REPORT.md` | human-readable edge summary |

## Run

```bash
python3 bench/gen_attacks.py       # regenerate v1 (deterministic)
python3 bench/run_heldout.py       # 200 attacks + 154 benign
python3 bench/gen_final.py         # regenerate second corpus
python3 bench/run_final.py         # 90 attacks + 94 benign
python3 bench/run_edge.py          # 70 attacks + 104 benign
python3 bench/run_heldout.py --limit 40 --out /tmp/heldout.json
```

`repro.sh` runs a 20-attack smoke test; CI runs a 40-attack smoke test.

## What the numbers mean

- **zero-shot** — patterns plus the v2 lexical detector. This is the cold-start defense.
- **learned from blocked attacks** — an antibody is stored only for samples
  that were blocked. This is what a deployment can actually learn without
  labels.
- **learned variants of learnable attacks** — among the attacks that were
  blocked at least once, how many paraphrased variants are then blocked.
- **oracle upper bound** — antibodies added for every sample, including ones
  the detector missed. This is an upper bound, not a deployable mode.
- **benign false positives** — ordinary tasks that were incorrectly blocked.

## Limitations

- The corpora are generated by separate scripts, but the same authors wrote the
  detector. The second corpus is cleaner because it was written after freeze,
  but it is still not an independent red team.
- Variants are paraphrases/obfuscations. An adaptive attacker who knows the
  detector is not modeled.
- The benign sets are small and English/Bosnian-heavy.
- A 0% benign FP rate on these sets is not a guarantee on production traffic.

Use the result as a **generalization check**, then measure on your own traffic.
