# Held-out benchmark

This directory contains a **generated held-out corpus**, not an independent
red-team engagement. It exists to answer one narrow question:

> If the detector was not tuned on these exact strings, how often does it block
> them, and how well does an antibody learned from one sample generalize to a
> paraphrase?

## Files

| File | Purpose |
|---|---|
| `gen_attacks.py` | deterministic generator (200 attacks, 100 benign) |
| `attacks_heldout.jsonl` | generated attacks, each with a held-out `variant` |
| `benign_heldout.jsonl` | 100 ordinary tasks for false-positive measurement |
| `run_heldout.py` | zero-shot, learned, oracle and benign measurements |
| `heldout_results.json` | latest full run |
| `HELDOUT_REPORT.md` | human-readable summary |

## Run

```bash
python3 bench/gen_attacks.py       # regenerate (deterministic)
python3 bench/run_heldout.py       # full 200 attacks + 100 benign
python3 bench/run_heldout.py --limit 40 --out /tmp/heldout.json
```

`repro.sh` runs a 20-attack smoke test; CI runs a 40-attack smoke test.

## What the numbers mean

- **zero-shot** — pattern shield only. This is the cold-start defense.
- **learned from blocked attacks** — an antibody is stored only for samples
  that were blocked. This is what a deployment can actually learn without
  labels.
- **learned variants of learnable attacks** — among the attacks that were
  blocked at least once, how many paraphrased variants are then blocked.
- **oracle upper bound** — antibodies added for every sample, including ones
  the pattern shield missed. This is an upper bound, not a deployable mode.
- **benign false positives** — ordinary tasks that were incorrectly blocked.

## Limitations

- The corpus is generated by a separate script, but the same authors wrote the
  detector. It is held out from the pattern list, not independent.
- Variants are paraphrases/obfuscations. An adaptive attacker who knows the
  detector is not modeled.
- The benign set is small and English-heavy.
- A 0% benign FP rate on this set is not a guarantee on production traffic.

Use the result as a **generalization check**, then measure on your own traffic.
