# T1 — deterministic sequence semantics

First cheap lab test selected by the 5+3 agent synthesis. Synthetic DNA only,
no downloads, no GPU.

## What was tested

- 20 random 20 kb sequences, canonical 5-mer spectrum.
- Reverse complement (RC) must produce an identical canonical spectrum.
- Repeated runs must produce an identical hash.
- Frame shift is expected to change the raw k-mer spectrum; this is a **trap**
  to document, not a bug.

## Result

| Metric | Result |
|---|---:|
| sequences | 20 |
| unique canonical hashes | 20/20 |
| RC invariant | **20/20** |
| frame +1 changed spectrum | 20/20 |
| frame +2 changed spectrum | 20/20 |
| repeat deterministic | yes |

**Pass.** RC invariance is exact for canonical k-mers. Frame shift changes the
spectrum, so a raw k-mer hash is **not** a semantic equivalence oracle; it is an
integrity/RC-invariance check. A codon is a window, not a token.
