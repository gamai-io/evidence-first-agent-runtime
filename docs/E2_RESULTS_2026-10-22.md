# E2 — lease-bound proof bundle (2026-10-22)

Prototype: `polymorph/lease_proof.py`. It binds a PROTEAN-style lease, a
proofgate-style report and an evidence record into one HMAC-signed bundle.

## Checks

Verifier is fail-closed on:

- HMAC signature
- audience
- expiry
- replay (`nonce` seen)
- `report.lease_id == lease.lease_id`
- `report.genome_hash == lease.genome_hash`
- `report.cmd_sha == lease.cmd_sha`
- `report.out_sha == evidence.out_sha`
- legal report status

## Results

| Case | Result |
|---|---|
| valid bundle | **accepted** |
| altered report `out_sha` | **denied** (`bad_signature`, `evidence_out_mismatch`) |
| altered lease id / genome / cmd | **denied** |
| altered evidence | **denied** |
| invalid status | **denied** |
| wrong audience | **denied** |
| expired lease | **denied** |
| replayed bundle | **denied on second use** |

**8/8 tamper cases denied, 1/1 replay denied, 0 false confirmations.**
Tests: `polymorph/tests/test_lease_proof.py` **5/5** (Contabo and VastVM).

## Limits

- HMAC key is a local lab key; production needs Ed25519 + offline custody,
  key ids, revocation and a trusted clock.
- The evidence source can still lie; this binds a claim to an execution record,
  not to source truth.
- Not integrated with the live PROTEAN adapter yet; this is the contract test.
