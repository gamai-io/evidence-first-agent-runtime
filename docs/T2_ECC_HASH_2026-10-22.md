# T2 — ECC + canonical AST hash

Second test selected by the synthesis. Synthetic programs only; mutants are
never executed. Stdlib only, <1 s.

## A. Canonical AST hash

40 base functions, 6 mutation classes × 40.

| Class | AST hash changed | Meaning |
|---|---:|---|
| rename | **100%** | semantics-preserving rename is **not** normalized |
| constant | **100%** | semantic change detected |
| control flow | **100%** | semantic change detected |
| dead code | **100%** | structural change detected |
| whitespace/format | **0%** | correctly ignored |
| unicode/comment | **0%** | correctly ignored |

**Honest reading:** the hash detects structural change and ignores format, but
it does **not** recognize alpha-renaming as equivalent. That is a false positive
if the goal is semantic equivalence; call it "structural change detection", not
"semantic proof".
