# E5 — shape-robust plan admission (2026-10-22)

E1 passed 20/20 benign and 40/40 explicit widening, but that corpus only
declares steps in the expected shape. E5 added 31 row-differential probes:
renamed envelopes, missing scope, nested `args`, extra fields, percent/fullwidth
traversal, duplicate keys, unknown ops and malformed types.

## Before the fix

| Failure | Count |
|---|---:|
| Uncaught capability widening | **8** |
| Fail-open malformed | **2** |
| Crashes instead of deny | **6** |
| Probes that changed the capability set | 25/31 |
| Paired lease vs immunity disagreement | 40.5% |

`agent-immunity` was also measured: 100/100 benign allowed, but only **20/100**
capability-widening text denied (80% false negative). It is an injection filter,
not a capability oracle.

## Fix

`polymorph/effect_lease.py` now rejects:

- renamed/missing/non-list `steps`
- unknown plan/step keys
- nested `args`, extra scope fields
- missing/null scope
- unknown ops and non-dict steps (structured deny, not exception)
- duplicate JSON keys via `loads_strict`
- percent-encoded and full-width path traversal (NFKC + unquote + normpath)

## After the fix

- 20/20 benign allowed, 40/40 explicit malicious denied, 0 FP/FN.
- Probe re-run: **8 -> 0** uncaught widening, **2 -> 0** fail-open malformed,
  **6 -> 0** crashes when `loads_strict` is used.
- Remaining limits: static checks cannot resolve symlinks; case-insensitive
  filesystems and path equality need runtime `openat2`; duplicate keys are only
  rejected if the caller uses `loads_strict`.
- False denies are intentional for `/IN` and `/in2` prefix lookalikes.

## Conclusion

Do not call E1 the security boundary. The boundary is **strict plan admission +
executed-byte binding (E2/TOCTOU) + lease**. The strict parser is the minimum
artifact; `probes.jsonl`/`gate.py` remain the regression gate.

Artifacts: `polymorph/effect_lease.py`, `polymorph/tests/run_tests.py` (15/15),
`docs/POLYMORPH_PLAN.md`.
